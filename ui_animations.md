# UI Animation Concepts for Arrland Missions

Based on the gameplay mechanics described in `DOCS/PRD-missios.md`, here are concepts for short (approx. 5-second) UI animations to enhance player feedback during key moments.

## 1. Ship Boarding Success

**Description:** A visual confirmation when a player successfully pays the ARRC fee and boards pirates onto a ship. An abstract representation of ARRC tokens flowing out, pirate icons moving onto a ship silhouette which then glows briefly to signify activation.

**Text Prompt:** "Subtle animation showing stylized coin icons (ARRC) flowing downwards and disappearing, followed by small pirate character icons smoothly sliding onto a waiting ship silhouette. The ship silhouette briefly pulses with a golden light, signifying activation. Background is a blurred tropical harbor scene. Style: Clean, stylized UI animation, 2D vector."

## 2. Mission Start: Resource Transfer/Trade

**Description:** Animation signifying the start of a transport or trade mission. Shows resource icons (e.g., wood, citrus) and ARRC coin icons being loaded onto a ship silhouette, which then smoothly sails off-screen or across a mini-map element.

**Text Prompt:** "UI animation: Resource icons (wood crate, orange fruit) and coin icons (ARRC) appear and slide onto a ship silhouette docked at an island icon. The ship silhouette then smoothly animates sailing away from the island icon across a stylized ocean background or minimal map line. Style: Clean, map-like UI animation, 2D vector."

## 3. Mission End: Successful Arrival

**Description:** Animation for when a ship successfully completes a transfer or trade mission. The ship silhouette sails back into view towards an island icon, and resource icons unload onto the island, possibly with a brief celebratory particle effect.

**Text Prompt:** "UI animation: A ship silhouette smoothly sails towards an island icon on a stylized map. Upon arrival, resource icons (wood crate, gold coin) slide off the ship onto the island icon, accompanied by a brief sparkle or confetti particle effect. Style: Clean, map-like UI animation, 2D vector."

## 4. Attack Mission Victory: Looting Resources

**Description:** Visual feedback for a successful attack where resources are looted. An animation showing the player's ship silhouette next to a damaged enemy ship silhouette, with resource icons flowing from the enemy ship to the player's ship.

**Text Prompt:** "Split-screen UI animation: Left side shows a victorious pirate ship silhouette. Right side shows a slightly damaged, darker enemy ship silhouette. Stylized resource icons (barrels, crates, coins) flow smoothly from the enemy ship towards the player's ship. A subtle 'victory' banner briefly appears. Style: Dynamic, stylized combat UI animation, 2D vector."

## 5. Ship Repair Complete

**Description:** Animation indicating a ship has been fully repaired at a port. Shows a ship silhouette with visual 'damage' marks (cracks, smoke) which then fade away, replaced by a healthy glow or sparkle, signifying restoration. Tools icons (hammer, planks) could briefly animate around it.

**Text Prompt:** "UI animation: A ship silhouette initially shows subtle crack lines and faint smoke wisps. Animated tool icons (hammer, saw, plank) briefly swirl around the ship. The damage marks fade away, and the ship silhouette brightens with a healthy shimmer or glow. Style: Clean, restorative UI animation, 2D vector."

## 6. Docking Slot Unavailable

**Description:** Feedback when a player tries to dock a ship at an island with no free slots. Shows the ship silhouette attempting to approach an island icon, but being gently 'repelled' by a subtle red 'X' or barrier animation appearing over the docking area.

**Text Prompt:** "UI animation: A ship silhouette attempts to move towards a dock icon next to an island. As it approaches, a soft red 'X' or a subtle translucent red barrier pulses briefly over the dock icon, gently pushing the ship silhouette back slightly. Style: Clear, informative UI animation, 2D vector, negative feedback."

## 7. Crew Assignment

**Description:** Animation visually confirming the assignment of NFT Pirates and non-NFT crewmen to a ship before boarding or mission start. Shows pirate/crew icons smoothly moving from a roster/panel onto designated slots on a ship diagram.

**Text Prompt:** "UI animation: Small, distinct icons representing NFT Pirates and generic crewmen slide smoothly from a side panel or list onto specific highlighted slots within a ship diagram or silhouette. Successful placement is confirmed with a brief green checkmark or pulse on each slot filled. Style: Organized, informative UI animation, 2D vector."
