# Islands Module

This directory contains contracts related to island management in the game.

## Contracts

### IslandRegionManagement.sol
Manages island regions and distances:
- Region assignment (North, South, East, West, Central)
- Coordinate system
- Distance calculations
- Travel time determination

## Integration
The islands system integrates with:
- Mission system for travel times
- Resource system for regional resources
- Trade system for route planning
- Battle system for engagement zones

## Features
- Geographic positioning
- Distance-based mechanics
- Regional characteristics
- Travel optimization
