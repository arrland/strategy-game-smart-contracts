# Trade Flow Infographic Prompt

## Purpose
Create an engaging, visually appealing infographic that explains how the trading system works in our blockchain strategy game. The infographic should be easily understood by non-technical players and illustrate the complete trading process from both island owner and ship captain perspectives.

## Target Audience
- Game players with no blockchain or technical knowledge
- Visual learners who prefer graphical explanations over text
- New players trying to understand the game's economy

## Key Elements to Include

### 1. Overview Section
- Title: "Trading in the High Seas - A Captain's Guide"
- Brief introduction explaining that trading involves island owners creating offers and ship captains fulfilling them
- Visual representation of the two trade types:
  * Ship buying resources from islands (with ARRC tokens flowing to island, resources to ship)
  * Ship selling resources to islands (with resources flowing to island, ARRC tokens to ship)

### 2. Preparation Visualization
- **For Island Owners:**
  * Illustration of an island with a trading post building
  * Visual of resource storage and ARRC token purse
  * Simple checklist: "Trading post built? ✓ Resources or ARRC tokens ready? ✓"

- **For Ship Captains:**
  * Illustration of a ship with crew members
  * Visual representation of cargo hold space
  * Simple checklist: "Ship ready? ✓ Crew aboard? ✓ Cargo space available? ✓"

### 3. Trading Process Flowchart
Create a side-by-side flow showing both paths:

**Left Side - Island Owner Journey:**
1. Island owner creates trade offer (sell or buy order)
2. Visual of resources moving to marketplace or ARRC tokens being set aside
3. Trade offer appears on a "market board" or "harbor notice"

**Right Side - Ship Captain Journey:**
1. Captain discovers trade offers at harbors
2. Prepares ship and selects destination
3. Travel visualization showing movement across a map
4. Arrival at trading island with exchange of goods/ARRC tokens
5. Return journey to home port

### 4. Timeline Visualization
Create a horizontal timeline showing:
- Offer creation
- Ship departure
- Outbound journey (with clock/hourglass icon)
- Trade exchange (with handshake icon)
- Return journey (with clock/hourglass icon)
- Mission completion

### 5. Benefits Section
Show visual representations of:
- Island owners getting needed resources or earning ARRC tokens
- Ship captains earning profits or acquiring valuable resources
- Economy flow with circular arrows showing how trade benefits everyone

## Detailed Trade Flow Process

### A. Selling Resources (Island Selling to Ship)
1. **Island Owner Preparation:**
   - Island collects resources through production or other means
   - Owner builds a trading post on their island
   - Owner creates a sell order specifying:
     * Resource type (e.g., wood, stone, food)
     * Amount to sell
     * Price per unit in ARRC tokens
   - Resources are moved to the marketplace awaiting buyers
   - Sell order appears in the trading post listings

2. **Ship Captain Response:**
   - Captain views available sell orders at different islands
   - Captain ensures ship has:
     * Enough cargo space for the resources
     * Enough ARRC tokens to pay for resources
     * Sufficient crew onboard
   - Captain plans route to the island selling resources
   - Captain initiates a trade mission selecting:
     * The specific sell order to fulfill
     * Amount of resources to purchase (can be partial order)

3. **Trading Journey:**
   - **Outbound Journey:**
     * Ship departs from home island
     * Travel time depends on ship speed and distance
     * ARRC tokens are reserved for the purchase
     * Ship travels across the map (visual journey)
   
   - **At Trading Island:**
     * Ship arrives at destination
     * Trade is automatically executed:
       * ARRC tokens transfer from ship to island owner
       * Resources transfer from marketplace to ship's cargo
     * Sale is recorded in both parties' trade histories
   
   - **Return Journey:**
     * Ship begins return journey to home island
     * Travel time equals outbound journey
     * Ship carries purchased resources in cargo hold
   
   - **Mission Completion:**
     * Ship arrives at home island
     * Resources become available for use
     * Trading mission is marked complete

### B. Buying Resources (Island Buying from Ship)
1. **Island Owner Preparation:**
   - Island owner identifies resources needed
   - Owner builds a trading post on their island
   - Owner creates a buy order specifying:
     * Resource type needed
     * Amount to buy
     * Price willing to pay per unit
   - ARRC tokens are set aside to guarantee payment
   - Buy order appears in the trading post listings

2. **Ship Captain Response:**
   - Captain views available buy orders at different islands
   - Captain ensures ship has:
     * The required resources in cargo (or can collect them)
     * Sufficient crew onboard
   - Captain plans route to the island buying resources
   - Captain initiates a trade mission selecting:
     * The specific buy order to fulfill
     * Amount of resources to sell (can be partial order)

3. **Trading Journey:**
   - **Outbound Journey:**
     * Ship departs carrying resources for sale
     * Travel time depends on ship speed and distance
     * Resources are reserved for the sale
     * Ship travels across the map (visual journey)
   
   - **At Trading Island:**
     * Ship arrives at destination
     * Trade is automatically executed:
       * Resources transfer from ship to island
       * ARRC tokens transfer from island to ship captain
     * Sale is recorded in both parties' trade histories
   
   - **Return Journey:**
     * Ship begins return journey to home island
     * Travel time equals outbound journey
     * Ship carries payment in ARRC tokens
   
   - **Mission Completion:**
     * Ship arrives at home island
     * ARRC tokens become available for use
     * Trading mission is marked complete

### C. Canceling Trade Orders
- Island owners can cancel unfulfilled orders at any time
- For sell orders: resources return to the island's storage
- For buy orders: reserved ARRC tokens are released back to owner
- Canceled orders disappear from the marketplace listings

## Twitter Optimization Guidelines

To ensure the infographic is optimized for Twitter sharing:

### Size and Format Requirements:
1. **Primary Option - Single Image:**
   - Dimensions: 1200 x 675 pixels (16:9 aspect ratio)
   - Maximum file size: 5MB
   - Format: PNG for best quality
   - Ensure text is large enough to be legible on mobile devices


### Content Considerations for Twitter:
1. **Readability:**
   - Ensure all text is minimum 14pt font size for legibility on mobile
   - Use high contrast between text and background
   - Avoid cluttering - fewer clear elements are better than many small details

2. **Engagement Features:**
   - Include game logo and Twitter handle in a corner
   - Add a clear call-to-action at the bottom (e.g., "Download now" or "Join the adventure")
   - Consider creating a branded hashtag for the trading system

3. **Technical Tips:**
   - Test the image at various sizes to ensure readability when scaled down
   - Preview on both light and dark mode to ensure visibility in both settings
   - Compress the final image appropriately to balance quality and loading speed


## Important Notes

1. Avoid technical terms like "smart contracts," "functions," or "blockchain"
2. Don't include code snippets or function names
3. Focus on the player experience rather than implementation details
4. Use metaphors that maritime/pirate game players would understand
5. Make it fun and exciting - trading should feel like an adventure!
6. Never use word credits or gold ALWAYS use ARRC tokens for this
